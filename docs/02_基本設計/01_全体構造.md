# 全体構造

## 構成

| 区分             | 役割                                                      |
| ---------------- | --------------------------------------------------------- |
| Astro            | 公開ページと多言語の静的出力を生成する                    |
| コンテンツ       | 学習分野、学び方、相談、料金、FAQなどの公開情報を保持する |
| Cloudflare Pages | GitHub連携で公開する                                      |
| Vectorize        | Productionで公開情報を補助検索する                        |

## 公開と検索

1. 変更はリポジトリでレビューする。
2. Cloudflare PagesがGitHub連携で公開する。
3. Productionでは公開済みのcorpusを検索用の派生データとして同期する。

Vectorizeが使えない場合の公開可否と検索の扱いは、運用設計で確認する。
